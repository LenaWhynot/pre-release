# /pre-release

Скилл Лены WhyNot для проверки сайта перед запуском. Работает с Claude Code и Codex.

Он помогает найти открытые ключи, ошибки в доступах и другие проблемы до публикации сайта. На выходе: что найдено, где находится проблема, что исправить и что ещё нужно проверить вручную.

В этом репозитории только **pre-release**: инструкция скилла, два локальных скрипта и чеклисты.

**[Скачать скилл ZIP](https://github.com/LenaWhynot/pre-release/archive/refs/heads/main.zip)**

## Установить через агента

Скопируйте в Claude Code или Codex:

```text
Установи скилл pre-release из https://github.com/LenaWhynot/pre-release.
Перед установкой прочитай его файлы. Скопируй всю папку скилла вместе со скриптами и чеклистами в папку навыков моего агента.
```

Или скачайте ZIP, распакуйте и переименуйте папку `pre-release-main` в `pre-release`. Скопируйте её целиком:

- Claude Code: `~/.claude/skills/pre-release/`
- Codex: `~/.agents/skills/pre-release/`

Установка этого скилла не требует ключей API, платёжных данных или подключения чужих сервисов. Для работы нужен доступ агента к вашему проекту, Bash и стандартные утилиты; Git нужен для проверки отслеживаемых файлов.

## Запустить

1. Откройте проект в Claude Code или Codex.
2. В Claude Code вызовите `/pre-release`. В Codex выберите навык `$pre-release`.
3. Посмотрите находки и список ручных проверок. При необходимости попросите сохранить отчёт локально.

Скилл начинает с проверок на чтение. Исправления, деплой, миграции и запросы к боевым сервисам требуют отдельной команды.

## Что проверяет

- Секретные ключи в коде и открытых файлах.
- Права доступа, админку и чужие данные.
- Формы, SQL-инъекции и XSS.
- Лимиты запросов, CORS и защитные заголовки.
- Подлинность платёжных вебхуков и повторную доставку событий.
- Готовность миграций, настройки рабочей версии и возможность отката.

Локальный сканер находит признаки проблем. Сценарии входа, настоящие права доступа и готовность отката нужно подтверждать отдельно. Скилл не гарантирует защиту от взлома.
